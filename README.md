# hay_v2_bot — Telegram-бот: поиск по своим данным (Haystack + Docling + Pinecone)

Вторая версия бота-ассистента с **модульной архитектурой**: компоненты и пайплайны
разнесены по файлам. Бот умеет всё, что умела v1 (диалог с памятью, инструменты —
факт о кошках, анализ собаки, погода), и добавляет **работу с файлами**:

* принимает PDF, DOCX, PPTX, XLSX, HTML, MD, TXT, CSV и картинки (OCR);
* разбирает файл через **Docling** и режет на структурные чанки (`HybridChunker`);
* сохраняет чанки в векторную базу **Pinecone** с метаданными (имя файла, номер чанка, страница);
* после загрузки присылает **резюме содержимого одним предложением**;
* отвечает на вопросы, учитывая найденные фрагменты документов (RAG) и историю диалога.

## Как это выглядит в чате

```
Пользователь:  [отправляет report.pdf]
Бот:           Файл получен. Запускаю анализ и сохранение. Это может занять немного времени…
Бот:           Готово. Я изучил этот файл, теперь можем его обсудить.
Бот:           Отчёт описывает финансовые результаты компании по кварталам.
Пользователь:  Какая выручка была во втором квартале?
Бот:           150 млн рублей (report.pdf, стр. 2).
```

## Структура

```
hay_v2_bot/
├── main.py                       # точка входа: сборка компонентов и пайплайнов
├── config.py                     # настройки из .env
├── components/                   # переиспользуемые компоненты
│   ├── docling_chunker.py        #   файл -> Docling -> чанки (Haystack-компонент)
│   ├── text_sampler.py           #   чанки -> текст для резюме
│   ├── context_builder.py        #   документы + память + история -> сообщения агенту
│   ├── context.py                #   Pinecone, эмбеддеры, ContextStore (запись/очистка)
│   ├── llm.py                    #   чат-генератор, Agent, системный промпт
│   └── tools.py                  #   инструменты: кошки, собаки, погода
├── pipelines/
│   ├── ingestion_pipeline.py     #   файл -> Docling -> эмбеддинги -> Pinecone (+ резюме)
│   └── generation_pipeline.py    #   вопрос -> поиск в Pinecone -> агент -> ответ
├── bot/
│   ├── assistant.py              #   логика без Telegram
│   └── telegram_bot.py           #   хендлеры Telegram
└── tests/test_offline.py         # тесты без ключей и сети
```

## Установка и запуск

Нужен Python 3.10+.

```bash
cd hay_v2_bot
python -m venv venv
venv\Scripts\activate        # Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env       # Linux/macOS: cp .env.example .env
```

Заполните `.env`: токен Telegram-бота (@BotFather), ключ ProxyAPI/OpenAI
(`OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1`) и ключ Pinecone. Индекс Pinecone
создаётся автоматически (serverless, cosine, 1536).

```bash
python main.py
```

При первом запуске Docling скачает свои модели (layout/OCR) — это занимает несколько минут.
Все вызовы OpenAI (чат и эмбеддинги `text-embedding-3-small`) идут **только через
`OPENAI_BASE_URL`**; локальных эмбеддингов (sentence-transformers) нет.

## Команды бота

| Команда | Действие |
|---|---|
| `/start`, `/help` | справка |
| `/files` | список загруженных документов |
| `/clear` | стереть историю и память сообщений |
| `/cleardocs` | удалить загруженные документы из базы |

Документы и память изолированы по `user_id`: бот ищет только в данных текущего пользователя.

## Тесты

```bash
python -m tests.test_offline
```

Проверяют Docling на реальном файле, метаданные чанков и сборку ingestion-пайплайна на заглушках.
